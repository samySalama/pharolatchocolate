# Pharolat Chocolate Store

واجهة متجر عربية RTL لعلامة Pharolat Chocolate، مبنية بـ HTML وCSS وJavaScript عادي، وجاهزة للنشر كـ static site على GitHub Pages أو أي استضافة ملفات ثابتة.

## المزايا الموجودة

- تصميم متكامل ومتجاوب للموبايل والتابلت والكمبيوتر.
- واجهة عربية RTL وهوية ألوان كريمي / إسبريسو / ذهبي.
- عرض المنتجات الـ 11 بالصور الموجودة في المشروع.
- اختيار ميلك أو دارك وتحديث السعر تلقائيًا.
- تحديد الكمية، البحث باسم المنتج، وترتيب المنتجات بالسعر أو الاسم.
- سلة جانبية قابلة للتعديل مع حفظ محتوياتها محليًا في المتصفح.
- نموذج إتمام طلب يجمع الاسم ورقم الهاتف والمنطقة والعنوان بالتفصيل.
- إنشاء رسالة واتساب بالمنتجات والأسعار والإجمالي وبيانات العميل.
- تكلفة التوصيل لا تُخمن؛ يتم تأكيدها حسب المنطقة في محادثة واتساب.
- تكبير صور المنتجات والمنيو، وروابط التواصل، وتحسينات الوصول ولوحة المفاتيح.

## تشغيل الموقع

افتح `index.html` في المتصفح. ولأفضل اختبار محلي، شغّل خادم ملفات ثابتة من مجلد المشروع، مثل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تعديل الأسعار أو المنتجات أو بيانات التواصل

كل البيانات التجارية في ملف واحد:

`assets/js/config.js`

تقدر تعدل منه:

- `whatsappNumber`: رقم واتساب بصيغة دولية من غير علامة +.
- `instagramHandle` و `instagramUrl`: اسم ورابط إنستجرام.
- `products`: أسماء المنتجات والأسعار وصورة كل منتج.
- `heroImage` و `menuImage`: صور الواجهة والمنيو.

مثال المنتج:

```js
{ id: 'lotus', number: 1, name: 'لوتس', english: 'LOTUS', image: 'assets/img/photos/lotus.jpg', milk: 150, dark: 140 }
```

الصور موجودة داخل `assets/img/photos/`. عند استبدال صورة، احتفظ بنفس اسم الملف أو حدّث مسار `image` في `config.js`.

## النشر على GitHub Pages

1. ارفع محتويات مجلد `pharolat-store` إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
2. افتح إعدادات المستودع ثم **Pages**.
3. اختر النشر من الفرع الرئيسي `main` والمجلد `/ (root)`، ثم احفظ.
4. افتح رابط الموقع بعد اكتمال النشر.

## ملاحظات مهمة

- المشروع Front-end ثابت، ولا يحتوي على قاعدة بيانات أو لوحة تحكم أو بوابة دفع.
- السلة محفوظة على نفس المتصفح والجهاز باستخدام `localStorage`، وليست سلة مشتركة بين أجهزة مختلفة.
- زر إتمام الطلب يفتح واتساب برسالة جاهزة؛ العميل يراجعها ويرسلها بنفسه.
- لا يتم تحصيل أو تخزين بيانات الدفع.
- لا توجد رسوم توصيل ثابتة في الموقع؛ يتم الاتفاق عليها حسب منطقة العميل.
